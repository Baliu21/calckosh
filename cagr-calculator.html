What CAGR is good for

CAGR is useful when you want one comparable annualized number for growth that happened over different time spans.

What CAGR hides

It says nothing about the route between the start and end. A smooth investment and a highly volatile investment can report the same CAGR if their endpoints match.

CAGR versus total return

Total return tells you the overall percentage change. CAGR annualizes that change while accounting for compounding and the length of the period.

Common questions

Does CAGR show what happened every year?

No. CAGR compresses the whole period into one constant annualized growth rate and hides the actual path and volatility.

Can CAGR be negative?

Yes. If the ending value is below the starting value, the annualized growth rate is negative.

What does doubling time mean here?

For a positive CAGR, it is the mathematical time a value would take to double if that exact constant compounded rate continued.
