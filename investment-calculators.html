Use fixed-return and market-return tools differently

FD and RD calculations model interest using the rate you enter. SIP and lumpsum tools model a hypothetical constant return, while real market returns vary.

Scenario ranges are more useful than one magic number

Long-term results can change sharply when return assumptions move by only a few percentage points. Where available, use the sensitivity tables rather than relying on a single output.

CAGR summarizes endpoints, not the journey

CAGR is excellent for annualizing growth between two values, but it hides volatility and the path taken between those values.
